# CLAUDE.md

Guidance for working in the **fifa-wc-2026** codebase.

## Stack

- **Next.js 15.5** (App Router) · **React 19.1** · **TypeScript 5.8**
- **Tailwind CSS v4** (`@tailwindcss/postcss`)
- Node **22.x**

## Scripts

- `npm run dev` — local dev server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — Next.js lint

## Coding rules

Follow these project rules when writing or reviewing code:

- @.claude/rules/nextjs.md — Next.js App Router conventions (Server/Client Components, data fetching, caching, Server Actions).
- @.claude/rules/react.md — React 19 + TypeScript component, hooks, performance, and accessibility rules.

- `PRODUCT.md` — product scope and requirements.
- `DESIGN.md` — design direction.
- `README.md` — project overview and setup.
